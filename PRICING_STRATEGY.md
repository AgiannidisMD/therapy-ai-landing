# MedScribe Pricing Strategy - 2-Tier Model

## 🎯 Recommended Pricing Model

### **Per-User Pricing with Unlimited Sessions**

This is the optimal model for healthcare SaaS because:
1. **Predictable costs** - Therapists know exactly what they'll pay
2. **No usage anxiety** - Won't worry about hitting session limits
3. **Scales naturally** - More users = more revenue
4. **Industry standard** - Matches competitor pricing models
5. **Simple billing** - Easy to calculate and explain

## 📊 Pricing Comparison vs Session-Based

### ❌ Session-Based Pricing (Not Recommended)
```
Bad Example:
€39/month - 50 sessions
€69/month - 150 sessions
€149/month - Unlimited sessions

Problems:
1. Therapists don't know how many sessions they'll do
2. Anxiety about hitting limits
3. Seasonal fluctuations (summer = fewer sessions)
4. Hard to predict revenue
5. Complex to explain
```

### ✅ Per-User Pricing (Recommended)
```
Good Example:
€49/user/month - Unlimited sessions

Benefits:
1. Predictable for customers
2. Predictable for you
3. Scales with team size
4. No usage anxiety
5. Simple to explain
```

## 💡 Alternative: Session-Based Safety Net

If you want a hybrid approach:

### Modified Model
```
Standard: €49/user/month
- Unlimited sessions (soft cap: 200/month per user)
- If user exceeds 200 sessions/month, contact them
- Most users do 80-120 sessions/month anyway

Enterprise: Custom pricing
- True unlimited
- No soft caps
```

**Why soft cap?**
- Prevents abuse (running a transcription business on your platform)
- 200 sessions/month = 50 sessions/week = 10 sessions/day (unrealistic)
- Average therapist does 80-100 sessions/month
- Gives you right to reach out if someone hits 200+

## 🚫 What NOT to Do

### ❌ Avoid These Pricing Mistakes

1. **Tiered session limits**
   - Creates anxiety
   - Unpredictable costs
   - Seasonal issues

2. **Feature gating on Standard**
   - Don't limit note formats (SOAP vs DAP)
   - Don't limit exports
   - Don't add watermarks
   - Give full value

3. **Nickel-and-diming**
   - No extra charges for:
     - Additional languages
     - More storage
     - More exports
     - PDF generation

4. **Complex pricing**
   - Avoid: "€0.50 per session + €29 base fee"
   - Keep it simple: "€49/user/month, unlimited"

5. **Undercutting on price**
   - Don't compete on being cheapest
   - You're selling time savings, not software
   - Premium pricing = premium perception

## 🧮 Break-Even Analysis

### Cost Structure (Per User/Month)

```
AI Costs:
- Whisper transcription: €0.40/session
- Claude note generation: €0.10/session
- Average: 80 sessions/month per user
- Total AI cost: €40/user/month

Infrastructure:
- Supabase: €0.50/user/month
- S3 storage: €0.10/user/month
- Vercel: €0.20/user/month
- Total infra: €0.80/user/month

Total cost per user: €40.80/month
Revenue per user: €49/month
Gross margin: €8.20/user/month (16.7%)
```

**Key insight:** Margin is thin at standard plan because AI costs are high. Enterprise plan with higher pricing is crucial for profitability.

### Improved Margin Strategy

**Option A: Increase base price**
```
€59/user/month
Gross margin: €18.20/user (30.8%)
Better, but may reduce conversions
```

**Option B: Annual-only pricing**
```
€49/month if annual (€588/year prepaid)
€59/month if monthly
Encourages annual (better cash flow + retention)
Maintains €49 price point for marketing
```

**Option C: Optimize AI costs**
```
Use Whisper API + Claude API directly
Negotiate volume pricing at scale
Build custom fine-tuned model (Year 2)
Target cost reduction: 30-40%
```

**Recommendation:** Implement Option B (annual discount strategy) + Option C (optimize costs as you scale)
